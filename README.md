# Guardian Agent · 小银智能银行助理

> 2026 第八届深圳国际金融科技大赛（FinTechathon）· 人工智能赛道参赛作品

一个会动手、但每一步都可追溯、可撤回、可接管的银行 AI 智能体。基于大语言模型 Function Calling，通过自然语言完成账户查询、转账汇款、账单分析、理财交易、卡片管理、订阅代扣与跨场景联动六类银行业务，所有资金类操作均经过风险分级、二次核验与审计留痕。

## 技术栈

- **认知内核**：DeepSeek-Chat（OpenAI 兼容接口，支持 Function Calling）
- **编排**：自研五段式 Agent 循环（理解 → 规划 → 执行 → 校验 → 回应）
- **业务底座**：SQLite 模拟银行核心（沙箱数据，每次启动重建）
- **界面**：Gradio 6.x，中英双语

## 快速启动

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置 API key
cp .env.example .env
# 编辑 .env，填入你自己的 DEEPSEEK_API_KEY（platform.deepseek.com）

# 3. 启动
python app.py
```

浏览器打开终端显示的地址（默认 http://127.0.0.1:7860 ，端口占用时自动顺延）。

## 已实现能力

**六大业务场景（17 个工具）**

| 场景 | 能力 |
|------|------|
| 智能转账 | 联系人转账、AA 拆分、定时转账、重复交易提醒、一键撤回 |
| 账单分析 | 月度报告、分类汇总、异常交易识别（大额/深夜/陌生商户） |
| 理财服务 | 产品推荐、风险测评、申购 / 赎回、持仓查询 |
| 卡片管理 | 状态查询、夜间锁卡、挂失（短信二次验证码） |
| 订阅代扣 | 自动续费识别、续费提醒、取消代扣 |
| 跨场景联动 | 生日预算锁定、代订鲜花、多步任务自动编排 |

**十二道安全防线**

1. L0–L4 五级风险分级（按金额/收款人/时段综合判定）
2. 余额不足实时拦截
3. 单笔金额上限与超余额阈值拦截（防手滑）
4. 单日累计限额控制
5. 交易密码二次核验（L3/L4 操作）
6. 短信动态验证码（卡片挂失）
7. 重复交易检测
8. 转账撤回窗口
9. 手机号 / 卡号敏感信息脱敏
10. 操作审计日志（带哈希链防篡改）
11. 提示注入防御（安全规则不可绕过）
12. L4 超权限操作转人工坐席
