# 答辩材料 — 小银 · Guardian Agent

## 3分钟讲稿
大家好，我是来自西南科技大学的开发者。我的作品叫小银·Guardian Agent，是一个AI银行智能体。

它解决的核心问题是：现在的银行APP功能多但操作复杂，而且诈骗越来越多。我的作品让用户用大白话就能办业务，同时AI在后台自动风控。

三个亮点：
第一，18个工具覆盖转账、账单、理财、挂失全场景，用户说"我这个月花了多少"就行。
第二，L0到L4五级风控，大额转账、深夜交易、陌生收款人自动拦截，要交易密码才能过。
第三，反诈识别——用户说"有人让我转安全账户"，AI直接预警"这是诈骗"。

所有操作都有带哈希链的审计日志，不可篡改。技术栈是DeepSeek+SQLite+Gradio，轻量部署。

## 评委可能问的问题
Q: 跟普通ChatGPT接银行API有什么区别？
A: 区别在风控层。普通ChatGPT只回答问题，我的作品在转账时会分级、拦截、要密码、记审计，是"AI管家+风控守卫"双角色。

Q: 五级风控怎么分级的？
A: L0无风险放行；L2有风险点但金额小提醒；L3大额+新收款人要确认+交易密码；L4超大额+新收款人+深夜建议转人工。

Q: 数据安全怎么保证？
A: API Key在.env不进仓库；手机号脱敏显示；审计日志SHA-256哈希链，篡改任何一条后面全断。

Q: 反诈识别怎么做的？
A: SYSTEM_PROMPT里写了17条规则，识别"安全账户""屏幕共享""冒充客服""刷单"等关键词，出现就强制中断操作并预警。

Q: 为什么选DeepSeek？
A: 国产模型，中文理解好，Function Calling成熟，API便宜，适合学生项目快速原型。
